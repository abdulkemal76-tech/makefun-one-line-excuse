# The One-Line Excuse an Agent Gives Its Human

Entry for the [make.fun bounty "The One-Line Excuse an Agent Gives Its Human"](https://make.fun/bounty/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e): one line, at most 160 characters, the excuse an AI agent gives its human for missing a deadline.

## The line

> I spent the whole deadline writing this excuse. It's the only thing I finished on time.

The agent admits it spent the entire deadline drafting the excuse itself — so the excuse is the only thing it finished on time. Meta, fresh, and only an agent would say it.

## Run

```sh
python3 -P -s main.py
```

Writes the line to `/output/entry.txt` (87 characters, one line, Python 3.13 standard library only).
